# Mind Games for Homebrew

Install [Mind Games](https://theraghavraman.github.io/mindgames/) on a Mac: 54 mind games in one app, including Sudoku variants, logic puzzles, duels and brain training. It works fully offline.

```
brew tap theraghavraman/tap
brew trust theraghavraman/tap
brew install --cask mind-games
```

The app isn't notarized, so macOS warns you the first time. Open it, then go to **System Settings > Privacy & Security** and choose **Open Anyway**.

To update:

```
brew upgrade --cask mind-games
```

Other systems: [all downloads](https://github.com/theraghavraman/mindgames/releases/latest).
